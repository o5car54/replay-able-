# The Hangover — poster

A self-contained "Hangover"-style movie one-sheet built from the lads'-night photos.

## Add your photos

Drop the 5 images into `poster/photos/` with these exact names:

| File | Which photo |
|------|-------------|
| `photo5.jpg` | **Group lineup** (the 6 lads) — this is the big hero image |
| `photo1.jpg` | Doorway / peace-sign / trainer shot |
| `photo2.jpg` | White satin outfit in the chair |
| `photo3.jpg` | Sunglasses selfie |
| `photo4.jpg` | The blurry hug |

(Any of the 4 strip photos are interchangeable — swap them to taste. JPG or PNG both work; keep the `.jpg` names or update the `src` paths in `index.html`.)

## See it

Open `poster/index.html` in any browser. It's one file, no build step, no internet needed.

To save as an image: browser **Print → Save as PDF**, or take a full-page screenshot.

## Change the text

All copy (title, tagline, credits) is plain text near the bottom of `index.html` —
edit `THE HANGOVER`, `Part IV — The Reunion`, the tagline and the credits block to whatever you like.
